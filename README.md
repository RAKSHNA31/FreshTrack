# 🥬 FreshTrack – Smart Pantry

FreshTrack is a responsive food expiry tracking web application that helps users manage food items and keep track of their expiry dates.

## 🚀 Features

* Add, edit, and delete food items
* Mark items as used or discarded
* Search and filter food items
* Sort items by expiry date
* Automatic expiry status tracking
* Dashboard with expiry statistics
* Expiry alerts and timeline
* Category overview and analytics
* Dark mode
* Export data as CSV
* Responsive design
* Data persistence using browser localStorage

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 📂 Project Structure

```text
FreshTrack/
```

## 💾 Data Storage

Food records are stored in the browser using `localStorage`. This allows the data to remain available after refreshing the page.

## ▶️ Run Locally

1. Clone or download the repository.
2. Open the project in VS Code.
3. Open `index.html` using a browser or VS Code Live Server.
